# Example Project

This is a sample feature note for [pogs-vault-sync](https://github.com/globo-gobo-99/pogs-vault-sync).

## Feature idea

Show the selected vault's local path after setup so the user can paste it into a new agent session. The code stays in its own Git checkout. This note records what the feature should do and links to a sketch.

## Try the drawing

Open [[Drawings/Example.excalidraw|the editable Excalidraw example]]. Select the text **Local vault** in the right-hand box and change it to **My vault**. Close and reopen the drawing to check your edit.

See [[Vault Guide]] for the example agent handoff.
