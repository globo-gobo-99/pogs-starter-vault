# Pogs Starter Vault

A small Obsidian vault you can use to try an agent handoff. It includes an editable Excalidraw drawing, a sample project note, and places for daily notes, clippings, and free-form notes.

## Try it in Obsidian

1. Download this repository as a ZIP or clone it. Copy the `vault/` folder to the location where you keep your Obsidian vaults. You can rename the copy.
2. In Obsidian, open the copied folder as a vault. Open [Vault Guide](vault/Vault%20Guide.md) to find your way around.
3. Install and enable [Excalidraw](https://community.obsidian.md/plugins/obsidian-excalidraw-plugin) on the device where you want to edit the drawing.
4. Open [Example Project](vault/Example%20Project.md) in Obsidian. Follow its drawing link, change the label in the right-hand box, then close and reopen the drawing to see your edit.

To try Daily Notes, enable the core **Daily notes** plugin and set the date format to `YYYY-MM-DD`, the new file location to `Daily`, and the template to `Templates/Daily`. [Obsidian Daily Notes guide](https://help.obsidian.md/plugins/daily-notes)

## Use it with an agent

Give the agent the absolute vault path on the machine where it runs and point it to `Vault Guide.md` and the project note. Keep code checkouts outside the vault. For a machine that needs a local copy of an existing Obsidian Sync vault, see [pogs-vault-sync](https://github.com/globo-gobo-99/pogs-vault-sync).

If you already use a vault, you can try the example by copying the project note and drawing into unused paths. Keep the drawing at `Drawings/Example.excalidraw.md` or adjust the link in the project note to match its new location.
